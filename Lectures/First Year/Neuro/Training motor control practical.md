# Training motor control practical

Training motor control practical
Learning Outcomes
Demonstrate some neurological skills for promoting motor control.
Demonstrate skills to provide muscle strengthening in neurological patients
Demonstrate skills for functional strength training using sit to stand
Task 1: Motor facilitation techniques
Tapping
Demonstrate tapping to facilitate activity in the following muscle groups: ankle dorsiflexors, knee flexors, knee extensors, hip flexors
Brief stretching
Demonstrate brief stretching technique to facilitate activity in the following muscle groups:  hip flexors
Weight bearing techniques
Demonstrate weight bearing technique to facilitate contraction in the following muscle groups:
Ankle, knee and hip muscles
Shoulder, elbow and wrist muscles
Task 2: Tone inhibition techniques
Passive movements
Demonstrate passive movement for the following lower limb joints: Hip Joint, knee joint and ankle joints
Passive stretches
Demonstrate passive stretches for the following muscles: hip flexors, hip adductors, Knee flexors, calf muscles
Task 3: Functional task training with sit to stand
Video 1: https://www.youtube.com/shorts/Aro79PYchS4
Using motor learning principles
Massed practice – using appropriate rest periods
External focus – focus on looking at the wall, pressure on the floor
Giving feedback – use mirrors/weighing scale/balance monitors
Random practice – sit to stand/walking practice/balance training combined
Task 4: Using Neuroplasticity
Repetition
Improving performance – use mirrors – for feedback, verbal feedback, weighing scale for feedback
Adding complexity to exercise – cognitive tasks, upper limb tasks
