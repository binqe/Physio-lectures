SPECIAL TESTS (as appropriate – based on our buckets from in class)
1. Degenerative Conditions (Spondylosis, facet arthropathy, disc degeneration, osteophytes)
Relevant Special Tests:
Cervical Quadrant Test (facet joint loading)
Spurling’s Test (for foraminal narrowing / radicular symptoms)
Cervical Distraction Test (relieves degenerative nerve compression)
Central and Unilateral PAIVMs (facet irritability)
Cervical Flexion–Rotation Test (CFRT) (upper cervical restriction)
2. Disc Pathology (Disc herniation, protrusion, radiculopathy, myelopathy)
For Disc Herniation / Radiculopathy
Spurling’s Test
Cervical Distraction Test
ULNTs 1–3
Quadrant Test
Valsalva Maneuver (if appropriate; increases intrathecal pressure)
For Myelopathy (Upper Motor Neuron involvement)
Babinski Response
Clonus (wrist or ankle)
Gait observation (broad-based, unsteady)
3. Mechanical / Postural Pain (Non-specific neck pain, upper crossed, muscle strain)
Typically no pathology-driven special tests — more movement quality + palpation based.
Useful Clinical Tests:
Scapular Assistance Test (mechanical/postural contributors)
Scapular Reposition Test
CFRT (cervicogenic headache from postural dysfunction)
Muscle Length Tests
Pectoralis minor length
Levator scapulae stretch
Upper trapezius stretch
4. Instability / Trauma (WAD, ligament sprain, fractures, facet dislocation)
These tests are ONLY done if safe and clinically justified.
Upper Cervical Instability Tests
Sharp-Purser Test (transverse ligament)
Alar Ligament Stress Test (alar ligament)
Anterior Shear Test (transverse ligament / atlas instability)
General Trauma Clearance
Canadian C-Spine Rules (if trauma and deciding need for imaging)
Neurological screen
Myelopathy testing (as above)
5. Nerve Entrapment / Neural Conditions (Radiculitis, TOS, Occipital neuralgia)
For Cervical Radiculitis
ULNTs/ULPTs
Spurling’s
Cervical Distraction Test
Shoulder Abduction Sign
For Thoracic Outlet Syndrome
Roos Test
Adson’s Test
Wright’s Hyperabduction Test
6. Inflammatory & Systemic Conditions (RA with A–A instability, AS, PMR)
If RA / suspected upper cervical instability
Sharp-Purser Test
Alar Ligament Stress Test
Anterior Shear Test
7. Non-MSK Cervical Pain (Meningitis, VBI/CAD, Tumour, Infection)
These are screening tests only — NOT provocative tests.
Vascular / Cervical Artery Dysfunction
Modified VBI/CAD screening
Sustained rotation
Looking for: nystagmus, dizziness, diplopia, dysarthria
(Avoid provocative VBI tests in modern practice.)
